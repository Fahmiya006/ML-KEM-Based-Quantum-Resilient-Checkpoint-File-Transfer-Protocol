**ML-KEM-Based Quantum-Resilient Checkpoint File Transfer Protocol**

A **quantum-resilient** and fault-tolerant **file transfer protocol** designed for secure data transmission over simulated **6G** networks.

The project uses ML-KEM for post-quantum key establishment, AES-256 for secure encryption, and checkpoint-based recovery to resume interrupted file transfers efficiently without retransmitting completed data.

🔑 Key Features

* ML-KEM – Post-quantum secure key establishment
* AES-256 – Secure file encryption
* Checkpoint Recovery – Resumes transfers from the last successful checkpoint
* 6G Network Simulation – Simulates latency, packet loss, and network interruptions
* Fault Tolerance – Improves reliability during unstable network conditions

🛠️ Technologies

* Python
* ML-KEM
* AES-256
* Post-Quantum Cryptography
* 6G Network Simulation

🎯 Objective

To develop a secure, quantum-resilient, and reliable file transfer mechanism capable of handling network interruptions efficiently in future 6G communication environments.
